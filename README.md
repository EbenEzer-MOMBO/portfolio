## 🚀 À Propos

Bienvenue sur mon portfolio professionnel ! Ce site présente mes projets et réalisations en tant que développeur full-stack. Il met en avant mes compétences en développement web et mobile, avec un focus particulier sur les solutions innovantes pour le marché gabonais.

## 💻 Projets Présentés

- **Eventime** - Plateforme de billetterie en ligne avec intégration Mobile Money
- **Pixel Gabon** - Solution e-commerce B2B avec système de gestion intégré
- Et plus encore...

## 🛠️ Technologies Utilisées

- [Astro](https://astro.build/) - Framework web performant
- HTML/CSS/JavaScript
- Responsive Design
- Intégration Continue

## 🚀 Installation

```bash
# Cloner le projet
git clone https://github.com/EbenEzer-MOMBO/portfolio.git

# Installer les dépendances
npm install

# Lancer en mode développement
npm run dev

# Construire pour la production
npm run build
```
